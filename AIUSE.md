# AI usage

This file tells users and contributors which AI tools the maintainer used in this
repository, for what, and who answers for the result. The rules for AI use in a
contribution are in [CONTRIBUTING.md](CONTRIBUTING.md).

Last updated: 2026-11-12

## Tools

| Tool | Model | Used for |
| :--- | :--- | :--- |
| Claude Code (Anthropic) | Claude Opus, Claude Sonnet | code, tests, docs, review |

## What AI was used for

- Code: drafting, refactoring and bug fixes, from a task the maintainer described.
- Tests: drafting tests and updating them when the source changed.
- Docs: drafting and editing the README and the docs in `docs/`.
- Review: reading diffs for bugs and style before a commit.

Design choices, logic semantics and releases are decided by the maintainer.

## Responsibility

Kim Quyen Ly reviewed every AI-assisted change and is responsible for the code,
tests and docs produced with AI help.

## Updating this file

When a new tool or model is used, add a row to the table and change the date.
