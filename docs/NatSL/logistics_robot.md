# Logistics Robot Example

A larger NatSL example is provided in:

- `examples/NatSL/logistics_robot.txt`
- `examples/NatSL/logistics_robot.formula.txt`

It complements the minimal regression models by exercising a multi-agent setting with bounded natural strategies and explicit strategy bindings.

The example is useful for checking:

- multiple agents;
- bounded strategy variables;
- explicit bindings between strategies and agents;
- interaction between existential and universal strategy choices;
- agreement between the `space` and `time` execution modes.

Additional compact examples are available in `examples/NatSL/`, including:

- `bounded_controller.txt`
- `bounded_opponent.txt`
- `restricted_two_agent.txt`
